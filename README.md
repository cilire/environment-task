# environment-task

#### Проект сделан, как тестовое задание для Win Wox Games.
Ресурсы со сцены были перенесены в папку Source, чтобы не мешать дальнейшей логике, которая могла быть в проекте. В папке Source располагаются папки:
- Materials
- Models
- Textures

Также в папке Models есть 3 подпапки: 
- AssetStore - модели из готовых ассетов
- Generated - модели, которые были сгенерированы нейросетью Tripo3D 2.5
- SelfMade - модели, которые были сделаны самостоятельно в Blender
